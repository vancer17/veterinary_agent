# 兽医语义分解与动态证据架构主旨

> **文档状态**：架构主旨基线
>
> **文档定位**：本文是后续语义分解、动态证据、问诊领域和生产接入架构
> 文档的最高层判断基准。它不替代详细架构文档，也不定义实现细节。

## 1. 核心主旨

兽医问诊语义和医疗知识表达都是开放集合，不能被预先穷举为固定槽位或全局
事实类型枚举。因此本架构采用：

```text
开放自然语言 proposition
+ 人工定义原子性与语义边界
+ LLM 根据输入动态分解粒度
+ 有限通用治理算子
+ 系统确定性绑定身份与应用结果
+ 患者事实、可信宠物事实与知识命题分源治理
+ 显式覆盖关系
+ 独立问诊策略与临床安全裁决
+ Fail Fast
```

更简洁地说：

```text
语义表达开放，治理方式收敛。
```

这条主旨同时约束两侧：

```text
1. 不把医疗语义压入固定枚举
2. 不因为语义开放而放弃审查、身份、追溯和失败治理
```

当前语义预处理各子层共享以下控制主旨：

```text
复杂审查可按有限缺陷组拆分，但结果必须由系统确定性合并；
修复必须按 target 缺陷簇局部执行，不得按缺陷码全局重写；
本地 selector 只是调用内定位符，不是长期身份；
当前会话由系统绑定单一宠物身份，模型输出仍必须形成自包含主体表达。
```

## 2. 架构覆盖范围

本文覆盖概念上的完整链路：

```text
用户当前回合表达
→ 原子自然语言事实分解
→ 患者事实治理与领域投影

已确认宠物背景事实
→ 只读可信事实输入

医疗 PDF 语料
→ 文档结构化知识 scope
→ 知识证据命题
→ 支持与等价审查
→ 确定性归一

患者事实 / 可信宠物事实 × 知识命题
→ 覆盖状态与来源绑定
→ 动态问诊策略
→ 阶段性回答或追问

独立临床安全链路
→ 独立安全裁决
```

本文不定义以上链路的具体实现方式。

## 3. 背景问题

### 3.1 固定槽位的失败

早期问诊链路将用户输入转换为固定核心槽位。该方式难以覆盖开放医疗文本，
且容易产生：

```text
槽位粒度不均
枚举外事实丢失
正常、否认、未知与未观察被压扁
机械补齐 missing slots
问诊策略退化为规则状态机
```

### 3.2 单体 one-pass 的失败

让一个模型调用同时完成事实抽取、维度归纳、来源判断、覆盖判断、追问决策
与回答生成，会导致：

```text
注意力分散
长结构输出漂移
模型自证来源与置信
患者事实与知识事实混用
失败被伪装为空结果
结果难以审查
```

### 3.3 语义维度穷举的退化风险

当系统为局部问题持续增加字段和阶段时，可能重新形成：

```text
事实类型枚举
时间类型枚举
量化维度枚举
症状专用处理管道
医学观察状态枚举
```

这与固定槽位问题本质相同，只是换了一层名称。

### 3.4 人工全量知识索引的不可维护性

医疗 PDF 中的叙述、表格、流程、指南、鉴别诊断和急症标准不会天然落成
统一字段。人工为每个病症维护完整证据需求索引成本极高，且容易重新变成
硬编码问诊槽位。

因此知识侧也必须采用：

```text
自然语言证据命题
+ 文档结构元数据
+ 显式审查与归一
```

## 4. 统一主语义对象：自包含自然语言 proposition

患者事实、可信宠物事实和知识证据命题的共同主表达是自包含自然语言
proposition。

它应表达：

```text
一个明确主体
在一个明确时间范围内的一个事件、状态或观察
```

患者事实示例：

```text
狗当前体重为15千克
狗历史体重为30千克
狗最近两天拒食
主人感觉狗明显消瘦
狗当前没有呕吐
```

知识证据命题示例：

```text
患病动物呕吐物中带有血丝
患病动物持续拒食超过一天
患病动物单日呕吐次数明显增加
```

时间、数量、单位、否定、确定性、频率、程度与归因应保留在 proposition
中，不应被拆散成全局枚举字段。

## 5. 原子事实分解原则

人工定义分解标准，不维护事实全集。

人工负责：

```text
定义什么是原子事实
定义必须拆分的 shared scope
定义不得过度拆分的属性组合
定义必须保留的语义差异
定义禁止添加的推断
定义失败状态与验收边界
```

LLM 负责：

```text
根据具体输入判断分解粒度
生成自然语言原子事实候选
```

例如：

```text
狗今天呕吐两次
```

是一个原子事实，不应拆成事件、时间与频率三条独立事实。

而：

```text
狗进食正常且饮水减少
```

应拆成两个独立观察事实。

可以有主 / 子模型协作，但调用边界必须固定，递归深度必须有界。模型不得
自由创建任务类型或无限继续分解。

## 6. 患者事实治理原则

当前回合患者事实来自用户表达，但必须先经过语义治理，才能进入动态证据
链路。

最低主旨要求：

```text
候选生成
语义忠实性审查
显式失败或修复治理
版本化身份
领域投影
```

下游问诊动态证据层不得重新读取原始用户文本，也不得把领域投影硬转换回
旧结构化抽取结果。

这样保证同一用户输入只有一条受治理的患者事实解释链。

## 7. 可信宠物事实原则

可信宠物事实是独立于当前回合患者事实的第二路只读输入。

其主旨形态是：

```text
宠物绑定身份
+ 已确认自包含自然语言事实列表
```

必须满足：

```text
只消费已确认事实
保留自然语言时间、否定、数量与单位
当前回合事实与可信宠物事实分源引用
冲突显式保留，不静默覆盖档案
```

不得引入：

```text
全局事实类型枚举
事实状态机
来源分类体系
原始记忆召回候选
```

未确认的长期记忆候选必须先经过独立记忆治理，不得直接进入可信事实输入。

## 8. PDF 结构化 RAG 原则

医疗知识检索不采用无结构的全局 top-k chunk 混合调用。

PDF 自身结构是知识 scope 的自然来源：

```text
文档标题
章节路径
病症或主题标题
页面范围
chunk 位置
解析质量
```

检索主旨：

```text
先形成候选知识 scope
再在单一 scope 内获取相关 chunk
不同病症 scope 的 chunk 不得混合调用
```

Scope 聚类只能影响召回、分组和调用边界，不是诊断实体，不是医学结论，
也不产生安全动作。

## 9. 知识证据命题原则

知识侧输出也是自包含自然语言 proposition，而不是孤立维度、问句或追问
指令。

知识命题必须：

```text
来自候选 scope 与具体来源片段
表达一个可观察的事件、状态或测量
保留时间、数量、单位、程度和否定方向
经过来源支持审查
经过等价或重复审查
由系统确定性归一
```

模型不输出来源自证。来源、文档、章节、页面和 scope 身份由系统根据调用
上下文绑定。

## 10. 有限治理算子

治理必须收敛为少量通用认知操作：

```text
候选生成
来源支持审查
等价或重复审查
覆盖状态审查
覆盖来源绑定
确定性应用与归一
策略应用
```

不得按医疗领域建立专用语义管道，例如：

```text
体重语义层
血压语义层
食欲语义层
行为语义层
时间语义层
```

模型输出关系必须保持薄结构、显式 selector 锚定和严格闭合校验。具体
JSON 契约由下游详细架构定义，本文不记录。

当单个审查步骤需要覆盖多个缺陷维度时，下游详细架构可以将相关维度分组
交给不同 LLM 调用，但必须满足：

```text
每组使用固定 allowlist；
输出仍为稀疏 Delta；
各组结果由系统确定性合并；
修复按 target 缺陷簇执行；
失败显式暴露。
```

## 11. LLM 与系统职责边界

### 11.1 LLM 职责

LLM 可以：

```text
分解自然语言粒度
生成候选 proposition
判断候选之间是否存在受控语义关系
判断知识命题与患者事实的覆盖候选关系
```

### 11.2 系统职责

系统必须：

```text
控制调用边界
绑定来源、版本与身份
执行结构闭合校验
应用确定性结果
映射失败状态
保存审计信封
```

系统还负责把当前会话绑定到唯一宠物身份。当前业务主路径是一次会话只绑定
一个宠物；模型可见上下文可以包含主体投影，也可以仅包含足够总结主体的
最小上下文。无论哪种形式，模型输出都不得保留未消解主体，也不得猜测
物种、名字或多宠物主体。

### 11.3 禁止行为

LLM 不得：

```text
自由创建任务类型
无限递归分解
自证来源
输出权威置信
直接修改权威事实
决定临床安全动作
失败后自行回退
```

## 12. 时间与量化语义

时间语义优先使用自然语言范围，例如：

```text
当前
今天
近期
持续超过一天
间歇性
长期
历史发生
目前无已知
时间不明
```

具体日期可以留在来源系统或审计元数据中，但不得作为问诊主语义维度。
系统不得从日期自行推断急性、慢性或其他医学分类。

量化事实应保留具体数值和单位。比较关系不得预先穷举生成，只能在下游
存在明确知识需求时，通过通用、有界、可审计的方式派生。

禁止建立全局量化维度枚举或体重、血压、血糖等专用比较管道。

## 13. 覆盖关系原则

动态问诊的核心不是固定槽位是否填满，而是知识侧需要的观察命题是否被
当前患者事实或可信宠物事实覆盖。

覆盖关系是三类事实的显式桥接：

```text
知识证据命题
×
当前患者事实
×
可信宠物事实
```

覆盖判断应分为两个认知对象：

```text
覆盖状态
支持来源
```

覆盖关系必须保留：

```text
正常不等于否认
否认不等于未知
未观察不等于绝对否认
部分覆盖不等于完全覆盖
历史事实不等于当前症状
无已知不等于绝对不存在
```

策略层只消费系统合并后的覆盖关系，不解析自然语言，不扫描关键词，不
重新读取原始用户文本。

## 14. 动态问诊策略原则

问诊策略根据以下输入决定回答、追问或拒绝：

```text
覆盖关系
用户意图
显式信息缺口
候选知识 scope
追问上限
既有会话状态
```

策略原则：

```text
优先公共关键证据与鉴别性证据
考虑信息增益和用户回答负担
answer_now 允许阶段性回答，但保留不确定性
gap 不自动等于强制追问
不机械选择缺失证据最少的候选病症
```

追问生成是策略之后的表达层，不决定是否追问。

## 15. 临床安全与长期记忆边界

动态证据层可以知道：

```text
还需要补充哪些观察证据
```

但不得产生：

```text
urgent signal
blocked signal
急诊结论
诊断结论
治疗方案
临床动作
```

临床安全裁决由既有独立链路负责，语义分解与动态证据层不得绕过或替代。

问询层也不得直接写入长期记忆或宠物档案。新的长期事实候选必须交给独立
记忆治理链路。

## 16. 旧槽位迁移原则

旧核心槽位不应继续作为问诊策略主输入。

迁移方向：

```text
阶段一：作为历史状态和旧提示词兼容视图
阶段二：仅在语义等价明确时从覆盖关系派生
阶段三：退出问诊策略主路径
```

不得为了兼容旧链路而把动态证据关系重新压回固定槽位状态机。

## 17. 生产接入与 Fail Fast

生产接入必须显式定义：

```text
路由配置
依赖就绪检查
失败映射
审计身份
回滚边界
```

所有失败必须显式暴露。

禁止：

```text
失败转空 facts
失败转空槽位
失败转空知识命题
失败后自动回退旧抽取器
宽松修复模型 JSON
使用关键词补造事实
把 partial 结果伪装为完整结果
```

旧链路只允许部署级或配置级显式回滚，不允许单次请求内静默切换。

## 18. 架构资产地图

以下资产已经形成主旨级共识。详细契约应由后续详细架构文档分别固化，
不得在本文中展开实现细节。

| 架构资产 | 主旨结论 |
|---|---|
| 原子事实分解 | 人工定义边界，LLM 动态分解，自包含 proposition 表达 |
| 语义预处理跨层控制 | 分组 Review、Delta 合并、target 缺陷簇、局部修复与统一重编号 |
| 公共基础设施 | 模型网关、Strict JSON、selector、审计与外部依赖端口由 core 统一承载 |
| 当前会话主体绑定 | 当前主路径单宠绑定；输出仍必须审查未消解指代 |
| 患者事实治理 | 患者事实必须经过审查、版本化和领域投影，下游不读原文 |
| 可信宠物事实 | 已确认自然语言事实独立输入，不引入事实分类状态机 |
| PDF 结构化 RAG | 以文档结构形成知识 scope，scope-first 检索 |
| 知识证据命题 | 自包含自然语言观察命题，来源由系统绑定 |
| 来源支持审查 | 无来源支持的候选不得进入有效集合 |
| 等价 / 重复审查 | 显式比较候选关系，系统确定性归一 |
| 覆盖关系 | 患者事实与知识需求的显式桥接 |
| 覆盖状态与来源分离 | 先判断状态，再绑定来源，二者严格校验 |
| 时间语义 | 自然语言范围保留在 proposition 中 |
| 量化语义 | 保留数值和单位，比较按需通用派生 |
| 动态问诊策略 | 基于覆盖关系与意图决策，不基于固定槽位 |
| 临床安全边界 | 安全裁决独立，不由问询层产生 |
| 旧槽位迁移 | 旧槽位退出主路径，仅作兼容视图 |
| 生产接入 | 显式路由、失败映射和部署级回滚 |

## 19. 防偏移清单

后续设计与实现不得引入：

```text
固定症状槽位作为主表达
全局事实类型枚举
全局语义维度枚举
全局时间类型枚举
全局量化维度枚举
领域专用语义处理管道
把同一事件的属性拆散成多条事实
模型自由递归分解
模型输出来源自证
模型输出权威置信
下游重新读取原始用户文本
患者事实与知识事实混成单一权威
可信宠物事实与当前患者事实身份混合
未确认记忆候选直接进入可信事实
Coverage 层扫描关键词
gap 直接变成强制追问
问诊层做临床安全裁决
问诊层写长期记忆
失败转空结果
单次请求自动回退
```

## 21. 变更原则
